## 车模改成写实侧视图 + 补奔驰宝马车型

**需求**：「把汽车模型库里的汽车图片改成更接近真实的。同时增加奔驰和宝马的车型」

**渲染层重写（`assets/js/cars.js`）**
- 车身轮廓从「几个控制点的多边形」改成**带圆角控制点的曲线路径**：`rpath(pts, rad)` 逐点算入点 / 出点，Q 曲线倒角，车身、玻璃共用同一套算法。注意**入点和出点都是 `p - v*rr`**（v2 是 `next→p`，方向相反），一开始写成加号会出现一圈尖刺。
- 轮拱用 `<path fill-rule="evenodd">` 从车身里**真的挖洞**（`archHoles()`），再铺一层 `#1A1A22` 的轮拱内阴影，车轮才是坐进翼子板里，不是贴在车身上。轮拱口 `r + 3.6`。
- 分层顺序：地面阴影 → 车身 → 车身内的下部压暗 / 肩线高光（用 `clipPath` 裁）→ 轮拱 → 玻璃（渐变 + 顶部压暗 + 两道斜向反光，用玻璃 clip）→ 腰线 / 门缝 / 把手 / B 柱 / 前后灯（**整组裁进车身轮廓**，灯不会戳出车外）→ 行李架 / 尾翼等车身外的点缀 → 后视镜 → 车轮。
- 车轮：深灰胎 + 顶部高光弧、可选白边胎（1950 年代车 `ww: 1`）、五辐轮毂（暗缝 + 银色辐条 + 中心盖）；灯具统一加一圈深色灯罩；四门车在侧窗 56% 处加 B 柱，不然像一整块大玻璃。
- 去掉原来车身上的白色品牌铭牌（最像玩具的地方）。单车 SVG 约 7KB，42 辆整柜约 297KB；今日页渲染实测 15~21ms，可接受。
- `svg()` / `shapes` / `byEra()` / `owned()` / `firstYear()` / `lastYear()` 接口没变，`today.js` 与徽章模块不用改。

**车型（28 → 42 辆）**
- 奔驰 9 辆：300SL、280SL 帕加达、G 级 W460、190E、560SEL、SLK、SLR McLaren、AMG GT、G 63。
- 宝马 8 辆：507、2002、3 系 E21、M3 E30 / E36 / E92、i8、i7。
- 新增 2 种造型：`fins50`（50 年代尾鳍，尾鳍做进车身轮廓而不是贴三角形）、`beetle`（圆顶甲壳虫）；重做 `suv`（G 级方盒子）、`cyber`（低车头斜线楔形）、`wedge`（Countach 大尾翼）。
- 星价改成按数组下标自动生成 `30 + i*20`（30 → 850），同年代内年份升序用脚本校验。

**踩坑**
- Headless 截图里 `U.h` 之类的手写 div 若用 `setAttribute('html', ...)` 不会解析 SVG，必须 `innerHTML`。
- 图鉴放大 3.9 倍时能看出「轮拱口太宽、灯像纸片、B 柱太浅」等问题，但这些在 66px 高的真实缩略图里都看不见；**按真实显示尺寸判断，不要被放大图带跑**。

## 车模按真实车型重做（1/64 模型式签名特征）

**需求**：「不是卡通和写实的问题，是现在的汽车图片和真实世界里该车型不匹配……可以参考车型的 1/64 模型。重做汽车图片。」
之前 42 辆车共用 14 个轮廓（NSX/RX-7/Supra/Veyron/R8/SLR 全用 `sport`，只换颜色），这是根因。

**`assets/js/cars.js` 重写**
- 数据层：`BASE` 22 个轮廓原型（紧凑点串 `'x,y x,y ...'` + 圆角串），`CARS` 每辆车 `shape / base / pts / tw / sig`，`makeShape()` 生成 **42 条两两不同的车身轮廓**（`pts` 精改控制点、`tw` 按区域微调车顶/引擎盖/前后悬/轮径）。新增 `cabrio`、`roadster`、`pagoda`（凹顶）、`gullwing`、`evlift`、`supercar00`、`u8`、`i8` 等原型。
- `svg()` 接口没变，`Cars.shapes[c.shape]` 仍是解析后的几何（smoke 有断言依赖）。
- `FEAT` 约 60 个车型签名特征，返回 `[车身内, 车身外]`：鸥翼门缝/侧鳃、帕加达凹顶、尾鳍+火箭尾灯、双色车顶、Mini 浮顶、侧凹+三竖条尾灯、跳灯、剪刀门、奶酪刨侧腮、大/小尾翼、宽体轮拱、G 级备胎+行李架+外露铰链、Testarossa 侧腮、Veyron C 形弧带、R8 侧刃、i8 浮空 C 柱、碳顶、贯穿尾灯、激光雷达、隐藏门把手、分体大灯、AMG 竖条格栅等。
- **三层绘制顺序很关键**：`paint`（双色/侧刃等色块，玻璃之前）→ 玻璃 → `inside`（门缝/灯具/线条，玻璃之后，另有车身 clip）→ `outside`（备胎/尾翼/立标/雷达）。双色/碳顶用 `矩形 + glassD` 复合路径 + `fill-rule="evenodd"` 挖掉侧窗，所以玻璃始终透明；一开始把色块画在玻璃之前只露 7px 车顶带，几乎看不见。

- 敞篷车风挡压低（凸起 20px→12px）+ 玻璃放大贴合 + 座舱头枕，不再像「戴帽子」。
- 配色：Bel Air 珊瑚红+白顶、Eldorado 金+白顶、Mini 红+白浮顶，保证双色对比肉眼可见。
