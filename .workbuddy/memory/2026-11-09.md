# 2026-11-09

## 徽章墙加密 + 今日任务页显示结果；小屋新增年代汽车模型

**需求**：「因为要一直做题，徽章墙增加一些，结果显示在今日任务页面。同时我的小屋里增加一些各种品牌的汽车模型，从50年代的车一直到现在的车。」

**徽章（新增 `assets/js/badges.js`）**
- 原来 8 枚写在 `growth.js` 里、判定是页面内的私有函数。抽成共享模块 `Badges`：`BADGES` 36 枚 / 9 组，`groups / all() / owned() / next() / highlights() / stats()`。
- `stats()` 一次扫描现有流水算出 15 个口径：连续打卡、累计答对、场次、三科答对数、单场全对 / 连续全对 / 完美一天、交作业次数、累计赚到的星星、车模收藏数、补练 / 周末 / 早起。
- **关键口径**：累计星星不能用 `Store.stars()` 余额（买装饰会花掉），改为 `答对数 + 交照片数 × 2`，与 `Task.completeSlot` 发星一致。不新增任何存档字段，旧数据直接兼容。
- `goal: -1` 的「满车库」徽章在运行时取 `Cars.all().length`，车模增减不用改徽章。
- `growth.js` 改为按组渲染 + 未解锁显示「还差 N」和进度条；`today.js` 新增「🏅 我的徽章」速览卡（chips / 数量 / 下一枚进度 / 跳徽章墙）。
- 新解锁提示用 `wb2_badgeseen_<kidId>`（沿用 Store 前缀，wipeAll / 快照 / 导出导入会带上）记已展示 id；首次只记录不庆祝，之后有新徽章才弹一次横幅 + 音效。

**汽车模型（新增 `assets/js/cars.js`）**
- 28 辆 / 8 个年代组（1954~2024），每年代 3~4 辆，覆盖大众、奔驰、雪佛兰、凯迪拉克、迷你、福特、保时捷、丰田、本田、兰博基尼、宝马、法拉利、马自达、布加迪、奥迪、特斯拉、蔚来、比亚迪、小米等。
- 13 种参数化 SVG 侧面造型（`__G__` 渐变 / `__C__` 车色 / `__D__` 描边占位），统一阴影、双轮、车窗、车灯、品牌小铭牌。离线可用，不依赖图片。
- 组内按年份从老到新，星价整体递增（30 → 800）；id 统一 `car_` 前缀，和原有 7 件装饰不冲突，旧存档兼容。
- `today.js` 小屋改成：房间装饰行 + 横向滚动车模展柜（已解锁彩色 / 未解锁灰度加锁，点击定位到对应年代商店）；商店加「装饰 / 车模」两个 tab，车模按年代分组。解锁后走 `App.render()` 重绘（原来是 `render(view, query)` 会把整页再追加一遍）。

**踩坑 / 可复用**
- 临时视觉页面里 `app.js` 会在 `DOMContentLoaded` 自动 `boot()` 并覆盖 `#view`、把 `#app` 重新显示；自定义图鉴必须挂独立容器 + `#app{display:none!important}`，否则截图永远是今日任务页。
- `file://` 下用 `?p=cars` 传模式不生效，改用 `location.hash` 判断。
- Edge headless `--screenshot` 生成的图片若复用同一文件名，看图工具可能给缓存内容；每轮换新文件名。
- `U.h` 的 `html` 属性可直接塞 SVG 字符串；`dataset` 属性可用来做商店年代锚点。
