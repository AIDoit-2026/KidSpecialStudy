## 去掉「写汉字/写拼音」预设（家长反馈：不用指定，当天自己选）

**背景**：家长中心原本有「写字内容」下拉（settings.writingMode），但实际需求是每次写字任务都把字和拼音一起给出，孩子/家长当天想写哪种写哪种，不做预设。

**改动**
- 删除 `settings.writingMode`（store.js）、家长中心下拉（parent.js，改为一行说明文字）、写字页的模式切换按钮与 `?mode=` 参数、session.writingMode。
- `writing.js`：每张字卡 = 田字格范字 + 四线三格拼音（`charCard` 合并了原 `pinyinCard`），拼音字号按音节长度缩放（len>=5 用 1.55*band），CSS `.char-card .py-grid{width:170px;--band:26px}`。
- `print.js`：写字单同时印「四、写字（田字格）」和「五、写拼音（四线三格）」，孩子挑一种写。
- `ai.js`：提示词改为**统一版**——明确「汉字或拼音都可以，孩子当天自己挑」，两套判分标准并列，禁止因只写一种扣分；要求模型返回 `script: "hanzi"|"pinyin"`，`applyResult` 把它写回 `rec.mode`。
- `ai.js` 新增 `DIM_CN_ANY`（写法正确/占格结构/整洁规范/完成度）与 `scriptCN`、`pickScript`；`modeOf` 改为「不知道就返回 null」，不再默认汉字。
- `review.js`：维度名按 `rec.mode` 三态取（拼音/汉字/中性），删掉上一版加的「按拼音/按汉字批改」按钮；预置评语合并成一套 9 条（汉字+拼音混排）。

**踩坑**
- `.sr-name` 只有 `width:96px`，窄屏被 flex 压成一字一行 → 加 `flex:0 0 96px; white-space:nowrap`。
- `.stars-pick button` 带浏览器默认 padding，5 颗星会把第 5 颗挤出卡片 → `padding:0;line-height:1`。

**验证**：假 OpenAI 接口（node http + CORS）端到端跑通「上传无 mode → AI 判定 pinyin → 记录 mode=pinyin → 维度名变字母形体」；冒烟测试 92 项 0 失败（新增：不预设模式、提示词两种都接受、script 写回 mode）；check-content ✅。

## 家长中心「看题」：按天预览练习题（检查题目质量）

**需求**：家长中心要能选日期，预看当天会出哪些题，方便检查题目质量。

**实现**
- `task.js` 的 `buildPlan(date, prog)` 增加可选进度参数；新增 `Task.preview(date)`：
  - 那天已有 `Store.day(date).plan` → 直接返回真实记录（`source:'record'`）
  - 今天或更早但没记录 → 用当前进度算一份（`estimate`）
  - 未来 → 从今天起逐天 `buildPlan` 并推进模拟游标（yw/sx/writingCursor/sessionsDone），推到目标日期（`sim`），只读不写盘
- 预览结果按 `kidId|date|册次|进度|设置` 做内存缓存 `PREVIEW_CACHE`（上限 80 条），保证「列表 → 详情 → 翻场次」看到同一份题；孩子做了一场后 key 变化自动失效。
- `parent.js` 新增 tab「看题」：日期 input（min/max ±365 天）+ 前一天/后一天/回到今天；显示日型、应完成场次、当天排几场/几题、来源说明；每场一张卡（语文/数学/写字 + 题型 pill + 看题目按钮）。
- 新增 `pages/peek.js`（`#/peek?date=&slot=`）：逐题列出题干、图示（复用 `App.pages.practice.renderFigure`）、选项（正确项绿色 + ✓）、答案、解析；底部场次前后翻。**加了家长锁**（`App.isUnlocked()`），否则孩子敲 URL 就能看答案。
- CSS 新增 `.peek-bar/.peek-meta/.peek-line/.peek-q` 一套样式。

**顺手修的真 bug**
`content/yw-builder.js` 的 `STRUCT_OPTS` 只有「左右/上下/独体」，字库里「半包围」(35 字)、「全包围」(4 字) 匹配不到，兜底成「独体字」→ 「国」被答成独体。改为 5 种候选 + 匹配不到时降级换题型（不出错题）。每道结构题仍是 3 个选项。

**验证**：冒烟 97 项 0 失败（新增 3 条预览断言 + 1 条结构题答案断言）；check-content ✅；全库答案校验脚本 0 错；页面前后端截图确认（锁屏/列表/详情/未来周末 5 场）。
