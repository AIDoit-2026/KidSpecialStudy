# 2026-11-16

## 新增：「恭喜获得」撒花弹层（买新车模时）

家长要求：换到新车的时候弹一个「恭喜获得」，带撒花动画。

### 实现

- `assets/js/util.js` 新增 `U.celebrate(opts)`
  - 全屏 `#celebrate-root` 里加一层 `.cf-mask`（role=dialog）：背景压暗 + 卡片 `cf-pop` 弹跳
  - 撒花**不用 canvas**：64 个 `<i class="cf-p">`，left / 尺寸 / 颜色 / 圆角 / 延迟 / 时长在 JS 里随机，
    横向漂移与翻转角度塞进 CSS 变量 `--dx` / `--rz`，轨迹交给 `@keyframes cf-fall`
  - `prefers-reduced-motion: reduce` 时不生成纸屑、卡片也不弹跳（`.cf-static`）
  - `opts`: `{ title, sub, svg, name, meta, extra, button, onClose }`
  - 关闭走 `.cf-out` 淡出 + 180ms 后移除；Esc / 点遮罩也能关；**连开两张会先收掉上一张**（不叠层）
- `assets/js/pages/today.js` 的 `buy()`：买到车模 → `U.celebrate()`（车模大图 + 车名 + 年份 / 年代 + 车库进度）；
  房间装饰仍走 `U.toast`，不打断。集齐全部 42 辆时文案换成「全部 42 辆都收齐了，满车库！」
- `assets/js/cars.js` 新增 `Cars.byId(id)`（之前只能 `all().filter`）
- `index.html` / `tools/smoke.html` 都加了 `<div id="celebrate-root">`
- `assets/css/app.css` 追加约 50 行：`.cf-mask / .cf-card / .cf-confetti / .cf-p` + 三个关键帧

### 踩坑

- **headless 截图看不到纸屑**：`--virtual-time-budget` 会把 CSS 动画直接跑到结束帧（100% 时 opacity 0）。
  截图时必须把每片纸屑 `animation-delay` 设成负值 + `animation-play-state: paused` 定格在中途，
  否则只能看到一张没撒花的卡片
- 回归时要断言「装饰不弹窗、车模才弹窗」：两条购买路径共用同一个 `buy()`

### 验证

- 探针实测：买装饰 `decorCard=false`；买车模 `carCard=true`、`pieces=64`、按钮「停进车库」、点完 `closed=true`、星星 600−20−30=550
