# 2026-11-04

## 补练机制改造 + 连续练习休息提醒

**需求**：补练不能只在周末，每天都能补，补几场家长控制；每天练习次数也家长控制；连续练到第 3 场要警告休息；原来写死的次数作为推荐值。

**改动**
- `schedule.js`：新增 `RECOMMENDED = {workCapacity:1, satCapacity:3, sunCapacity:2, holidayCapacity:3, catchupExtra:2}` 并导出；`capacity()` 增加工作日分支（`settings.workCapacity`，默认 1）；`catchupRoom()` **去掉 dayType 判断**，任何一天都返回 `catchupExtra`（0 = 不补）。`catchupEta` 因此会自动算上工作日。
- `store.js`：defaultSettings 增加 `workCapacity: 1`，注释标明推荐值。
- `task.js`：新增连续练习判定
  - `BREAK_MIN = 25`（相邻两场空档 ≤25 分钟算「连着练」）、`REST_AFTER = 2`
  - `streakInfo(date)` 从最近完成的一场往前数（先按 startedAt 排序，防乱序完成），缺时间戳按连续算
  - `shouldRest(date, slot)`：slot ≥ 2 且 streak ≥ 2 且 `day.restAck < slot`
  - `restGate()` 弹窗（☕ 先休息一下 / 我还想接着练，两个选项都写 `day.restAck`），`restGateIfNeeded()` 无需拦截时直接 resolve(true)
  - `previewKey` 补 `st.workCapacity`
- `pages/practice.js`：render 开头拦截 `shouldRest`（先渲染一张 ☕ 占位卡，选「接着练」后 `App.render()` 放行）；首次进入时把 `session.startedAt` 写进 day，供后面的间隔计算。
- `pages/today.js`：`startSlot(slot, module)` 统一入口（开始按钮 / 场次条 / 四张任务卡都走它）；连着 ≥2 场时插一张浅蓝提示卡；规则文案带上 workCapacity 与 catchupExtra。
- `pages/parent.js`：排程卡改成 5 个下拉（工作日/周六/周日/节假日 1~5 场 + 每天最多补几场 0~5，0 显示「不补」），标签写「（推荐 N）」，值只写「N 场」避免 select 截断；规则说明用 `refreshRule()` 原地刷新；新增「🎯 场次恢复推荐值」按钮。
- `tools/smoke.html`：新增 12 条断言（推荐值、工作日可补、补练可设 0、工作日场次可改、补练上限跟设置、连续 2/3 场、歇够不提醒、ack 不重复提醒）。109 项 0 失败。
- README 同步场次说明与冒烟项数。
