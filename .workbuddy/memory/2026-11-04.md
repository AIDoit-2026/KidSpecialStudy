## 数学新增题型：比较式填数（□ + 2 < 5 最大填几）

**需求**：一边两数加减、一边一个数，用 > / < 连接，挖掉其中一个数问「最大/最小能填几」；挖第二个数、算式在右边都要有；按教材进度只出 10 以内，难度循序渐进。

**改动**
- `content/sx-builder.js`
  - `relOf(p)`：算式在右时显示符号要翻（`9 > □ + 4` 等价于 `□ + 4 < 9`），内部统一按「算式 ⋈ 数字」判。
  - `solveIneq(p)`：枚举 0..10 找极值。**三重拦截**——空位数必须正好 1；问最大时 last 顶到上限、或 last+1 的得数超范围，都返回 null（后者是关键：`□ + 1 > 5` 的「最大」会因为 10+1 超出 10 以内被误算成 9，孩子会问为什么不是更大）；问最小对称处理。
  - `TPL.ineq({op,a,b,c,cmp,side,ask,level,skill,max})`：a/b 传 null 表示空位；answer 由 solveIneq 算，无唯一答案直接 throw；explain 用「填 4：4+4=8，9>8；填 5：9>9 就不成立」的口径，方向和题目显示一致（side='rhs' 时写 `9 > 8` 而不是 `8 < 9`）。
  - `checkIneq(it)`：给 check-content 用的答案复核。
  - **题干只写「□ 里最大能填几？」**，算式交给图渲染；`audio` 另给完整读法（「方框里最大能填几？方框 加 1 小于 5」）。
- `pages/practice.js`：`renderFigure` 新增 `type:'cmp'`，空位虚线框、数字实线框（复用 `.fig-box.filled`）。
- `pages/mistakes.js`：错题本补渲染图示（`.mi-fig`），顺手修好「看图列式」类题在错题本里看不到图的老问题；CSS 里把 mi-fig 里的方框缩到 34px。
- `content/sx-1a.js`：替换 5 处现有题（保持每节点 5 题），按课时递进：
  1. u1-n8 5以内综合：`□ + 1 < 5` 最大 3
  2. u2-n4 6、7的加减法：`□ + 2 > 6` 最小 5
  3. u2-n7 8、9的加减法：`9 < □ + 4` 最小 6（算式在右）
  4. u2-n10 10的加减法：`10 − □ > 3` 最大 6（减法挖减数）
  5. u2-n12 10以内综合：`7 > 10 − □` 最小 4（减法 + 右置 + 求最小）
  覆盖：加 3 / 减 2，挖第一个 3 / 挖第二个 2，左 3 / 右 2，最大 2 / 最小 3。
- `tools/check-content.js`：新增「比较式填数」段，校验答案、10 以内、空格数、比较符，并打印覆盖度。
- `tools/smoke.html`：+11 项断言（题量、答案一致、数值范围、空位数、位置/符号/运算/极值方向覆盖、无界组合拒绝、渲染出 3 个方框且 2 实 1 虚），109 → 120 项。
- README 同步题型说明与冒烟项数。

## 比较式填数铺满全年级（每次练习 1~3 道）

用户反馈「一共只有 5 题」，要求数学第 2 单元起直到一年级结束、每次练习都有 1~3 道。

**做法：改成「按节点程序生成」，不再手写**
- `content/sx-builder.js` 新增 `TIERS`（w5 / w10 / w20 / w100e / w100）与 `ineqPack({tier,count,seed,avoid})`：
  - 先生成答案 `ans` 和另一个数，再按「得数随 x 变大/变小」反推比较对象 `c = v ± 1`，最后用 `solveIneq` 复核；
  - 分档限制 `minC`（比较对象的下限）、`minAns`（求最小时答案 ≥2，别出送分题）、`minOther`；
  - 固定种子（FNV+mulberry）→ 同一节点每次都出同一批题，预览/打印/错题本一致；
  - `avoid` 数组按**册**共用（`decorate` 预填手写题的指纹），手写题和生成题一起跨节点去重。
- `decorate(units, rules)`：按单元铺，节点题量 = base（首节点 base-1，整理复习 base+1，封顶 3），并在节点上记 `n.ineq` 供自检；`build()` 把它带出来。
- 数域跟着教材：一上 u1（5以内，从「加法」n5 起）→ u2（10）→ u3 图形 1 道 → u4/u5（20）→ u6 复习 3 道；一下 u1/u3/u5 各 1 道、u2/u4 各 2 道、u6 用 w100e（另一位只取一位数）、u7/u8 用 w100。
- 结果：数学一上 44 节点 296 题（比较式 76）、一下 45 节点 306 题（81），全册比较式 157 道，答案零错、无重复。
- 5 个原本被替换掉一题的老节点（u1-n8、u2-n4/n7/n10/n12）各补回 1 道常规题，保证「5 常规 + 1~3 比较」统一。

**每场练习怎么带上**
- `assets/js/task.js` 新增 `pickMath(items, n)`：常规题取前 n 道，本节点的比较式全部带上，插在 1/3/5 位（先热身再上反着想的）；末尾留常规题，错题复习替换不会顶掉它。
- `ensureCmp(ids, date, slot)`：数学内容走完后从全册抽巩固题，没抽到就按日期哈希补一道。
- `PLAN_VERSION = 2` + `touched()`：还没开始做的旧计划（planVersion 对不上）在 `ensure()` 时自动 `rebuild`，避免改完当天看到的还是老计划。

- 冒烟 120 → 124 项全过（新增：一下全覆盖、一上空节点只许 6 个、每节点 ≤3、pickMath 每场都带上且常规题仍是 5 道）。
