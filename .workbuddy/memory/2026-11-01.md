# 2026-11-01

## 需求变更：每天固定场次（工作日 1 / 周六 3 / 周日 2 / 节假日 3）

原模型：`1 + min(欠账, 容量-1)`，容量只是"上限"，没欠账时只有 1 场。
新模型：容量 = **当天应完成的目标场次**，全部做完才算打卡完成。

改动：
- `schedule.js`：`capacity()` 按星期区分（六 3 / 日 2，工作日 1，节假日 3）；
  新增 `catchupRoom()`（工作日 0，周末/节假日 = catchupExtra，默认 2）；
  `expectedSessions()` 改为逐日累加当日目标（原来按自然日数）；
  `plannedSessions() = capacity + min(欠账, catchupRoom)`；`catchupEta` 同步。
- `task.js`：`buildPlan` 新增 `target`，`i >= target` 才是 `catchup`，否则 `new`/`extra`；
  `extra`（当天第 2、3 场）写字量不缩水，`catchup` 才减半；summary 里 backlog 传 st。
- `store.js`：defaultSettings 去掉 `weekCapacity`，加 `satCapacity:3 / sunCapacity:2 / holidayCapacity:3 / catchupExtra:2`
  （settings() 会自动给旧数据补默认值，旧用户升级即 3/2）。
- `parent.js`：设置页三个下拉（周六 / 周日 / 法定节假日），文案改为"应完成"口径。
- `today.js`：场次条 extra 显示"加练"；当 `planned < capacity` 时给黄条提示（未做题可一键重排，已做题只说明明天生效）。
- `done.js` / `export.js`：补练/加练文案与"应完成 N 场"。
- `tools/smoke.html`：更新排程断言（周六 3 / 周日 2 / 欠账按目标累加 / 加练不减写字 / 补练上限 2 场）。
- `README.md`：规则段落重写。

验证（jsdom，临时装依赖后已清理）：容量四类日期、跨周累加、无欠账 3/2/1、欠 1 场周六 4 场、
欠 9 场周六封顶 5 场、buildPlan 类型 new/extra/extra(/catchup)、写字量、今日页"今日 0/2 场"均通过。

## 注意
- `Task.ensure()` 不会重建已有计划，改设置后当天需重排（今日页黄条 / 设置页"重排今日任务"）。
- 场次是"目标"，欠账只在周末/节假日额外补，上限 2 场。
