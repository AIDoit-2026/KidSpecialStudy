## 参考第 9、10 周老师试卷，做一份两单元 A4 模拟卷

**背景**：用户给了两份老师出的周末闯关 PDF（第八周 10.30、第十周 11.6），要求「整合参考、模仿出题，A4 打印 2 页」。

**做法**
- 用 `workbuddy-pdf` 读 PDF：`-f md` 提文字、`-f png` 渲染整页。中文路径渲染会失败，先 `cp` 到 ASCII 临时路径。
- 注意：CLI 的 `-f png` 对多页 PDF 只输出 page-0001（后页被同名覆盖），要看第 2 页得先 `-f split` 拆页；`--image-dir` 抽不出内嵌图（返回 could not be written）。第 2 页最终靠 `-f structure` 的 JSON 读版面。
- 归纳两份卷子的题型骨架：看图写算式（大括号）、□最大/最小能填几、比一比、等式两边填数、数一数几盘（第几盘/从左从右）、相邻数与前后第几个、数轴跳格、数阵、选一选、看图列式（一图四式）、解决问题、挑战题（凑等式）。

**产出**（`docs/试卷/`）
- `一上数学-第1-2单元综合闯关-A4.html`：12 道大题、满分 100（8+12+10+10+10+8+4+6+6+8+10+8），严格 2 页 A4。
- `一上数学-第1-2单元综合闯关-答案.html`：双栏答案 + 批改提示，1 页。

**技术要点（可复用）**
- 版式用固定 `.page { width:210mm; height:297mm }` + `@page{margin:0}` + `page-break-after`，`@media print` 里干掉外边距。
- 排版是否溢出必须实测：在页面里塞一段临时脚本，把每页最后一个子元素的 `bottom` 和页高写进 `document.title`，再用 Edge `--headless=new --dump-dom` 抓 `<title>`。比看截图准得多。同理可查 `cell.right > parent.right` 检测单元格溢出。
- 截图核对整页时，视口设 `810×1175`（1:1），整页 2350 高会被缩到 400px 宽看不清。
- SVG 默认 `overflow:hidden`，文字基线贴着 viewBox 底边会被裁掉半个字，viewBox 要留 6~8px 余量。
- 大括号（横向）用三段贝塞尔：`M x1 y C x1 y+7, ... xm y+d ... C ... x2 y`，不要用固定偏移，否则只画出一个小钩。
- 双栏答案页里，算式必须 `display:inline-block; white-space:nowrap`，否则 `2 + 6 <` 会被折到下一行接 `9`。
- 页眉用 `<ruby>` 注音只给难句加，整篇加会挤。

**踩坑**
- 第二页内容一开始超 180px。反复调字号/图形尺寸后，最后用「第六大题挪到第一页 + 第二页单独用 `#p2` 覆盖字号行距」平衡，两页余量各 25/29px。
- `#p2` 规则第一次误插进 `@media print` 块里，屏幕测量不生效，排查了一轮。
- 数阵第一版圆圈直径不到 1.4cm，孩子写不下，改成六角形 7 点布局（中心 + 6 点，三条线）才够大。

## 把周末闯关变式题 + 后段单元同步题分散进每日练习，并防完全重复
