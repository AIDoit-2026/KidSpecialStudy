# 2026-10-31

## 修复：AI 打分成功但批改页不显示分数/星星/评语

根因（三处叠加）：
1. `ai.js` 的 prompt 要求模型输出扁平 JSON `{stroke,structure,clean,complete,note}`，
   而 `applyResult` 只读 `r.scores.*` → 全为 undefined → 旧 `clampScore` 兜底成 **1 分**，
   真实分数被吃掉。
2. `review.js` 首次渲染没调用 `paint()`，均分 pill 一直是硬编码的「均分 3.0」。
3. `util.js` 的 `U.h` 用 `setAttribute('value')`，textarea 不生效 → 评语框永远空白。
   附带影响 `parent.js` 的节假日编辑框（同样不显示已有内容）。
4. `parent.js` AI 直连按钮里 `r.scores.stroke` 在扁平结构下抛 TypeError，导致 `App.render()` 不执行。

改动：
- `ai.js`：新增 `normScore`（无效返回 null）/ `pickScores` / `pickNote` / `normalize`，
  同时兼容 `scores` 包装、扁平、`score`/`result` 字段；prompt 改为规范格式；
  无有效分数时整条跳过不写入（记入 missed）；`scoreDirect` 返回规范化对象。
- `util.js`：`U.h` 对 value 改为属性赋值（`'value' in node`）。
- `review.js`：渲染末尾 `paint()`；`ta.value = note`；AI 打分后先同步本地再 `App.render()`；
  新增 `norm()` / `reviewerText()`，AI 评分显示来源 pill。
- `parent.js`：`avgScore()` / `reviewerText()` 健壮取值；AI toast 不再因 undefined 崩溃。
- `store.js`：VERSION 3→4，v4 迁移清理「AI 评 + 四维全 1」的坏数据，退回待批改（照片保留）。

验证：node vm 单测 9 例全过（扁平/包装/字符串/小数/越界/缺失/无效）；
jsdom 冒烟渲染批改页，星星 4/3/5/2、均分 3.5、评语、AI 标记全部正确（临时依赖已删除）。
