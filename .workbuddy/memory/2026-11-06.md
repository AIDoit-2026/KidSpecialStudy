## 修复「回到开始练习总显示第一场」+ 写字可家长跳过 + 交照片即完成

用户口径：「练习完成以后，进入家长评分再回到开始练习，经常会显示处于第一场，这个状态不对」「写字可以家长跳过，必须输入家长密码，就是说可以不写」「提交照片以后，不管 AI 有没有评分完成，都算完成写字任务」。

**Bug 根因（不是状态丢失，是路由没带场次）**：`app.js` 的 `NAV` 里「开始练习 / 写字打卡」写死 `#/practice` / `#/writing`，而 `practice.js` / `writing.js` 原来都用 `Number(query.slot || 0)`，缺省即 0。今日页和完成页的按钮是带 slot 的，所以「有时正常」；从侧栏、批改页、浏览器后退回来就落回第 1 场，答完的题又触发 `finish()` 跳第 1 场写字页。AI 打分成功后 `aiScore()` 会 `App.go('#/review?...')`，用户没点「完成打卡」就走人，本场 `status` 还是 todo —— 于是「去家长评分再回来」必然重现。

**统一口径 `Task.currentSlot(date)`**：第一个 `status !== 'done'` 的场次，全部完成返回 -1。`practice.js` 在 URL 无 slot **或显式 slot 指向已完成场次**时都改到 currentSlot，全部完成显示「今天的场次都做完啦」卡片；`writing.js` / `print.js` 无 slot 时同样定位；`today.js` 的 curIdx、`done.js` 的「继续下一场」（原来是 `sum.doneCount`，跳着做场次会算错）全换成这个函数。

**`Task.writingOK(s)`**：`!chars.length || photoId || writingSkipped` 即算写字完成。`canCheckin` / `completeSlot` 的 `day.done`、`day.checkedIn` / `checkedIn` 老数据兜底全部改用它。**关键坑**：`completeSlot` 原来写 `x.chars.length ? !!x.photoId : true`，家长跳过后这一场永远不算完成，`day.done` 会一直是 false。

**写字可跳过**：`writing.js` 加「🔒 今天不写字，家长跳过（需密码）」→ `App.requirePin({ force: true })`，force 必须带，否则家长中心解锁后的 30 分钟内会被 `Date.now() < unlockedUntil` 直接放行；通过写 `session.writingSkipped/writingSkippedAt`。不提供「撤销跳过」（本场一旦结算，撤销会让 `day.done` 与已发星星对不上），但补写交照片会清掉 `writingSkipped` 覆盖回来。已结算的场次隐藏照片「删除」按钮，同理。

**交照片即完成**：照片回调里落 `writingDoneAt`，并调 `settleIfReady()` —— 三科答完 + `canCheckin` 就直接 `completeSlot`，**不等 AI 点评，也不等用户点「完成打卡」**。这样家长中途去评分回来，计划已推进到下一场，正是对 bug 场景的根治。底部按钮用 `paintFoot()` 局部重绘（不整页 `App.render()`，否则无 slot 的 hash 会立刻跳到下一场写字页）；上传区 `paintZone()` 同步显示「写字任务就算完成，AI 点评不影响」。`practice.finish()` 也改成只有 `!writingOK(s)` 才去写字页。

**同步**：家长中心概览加「交照片就算完成，待批改只是点评队列」说明；README 孩子端流程加第 6 条「接着练」、修正过期的题量描述、冒烟项数 150 → 167。`smoke.html` 新增 `writingFlow()` 真实路由流程（批改页 → `#/practice` → 旧链接 `#/practice?slot=0` → 写字页点跳过 → 第 3 场 → 全部完成），另外加 `writingOK` / `currentSlot` / AI 未点评仍可打卡等同步断言。

**踩坑（测试脚本）**：① 一开始把第 2、3 场答案也填满了，`practice` 直接 `finish()` 跳写字页，`.stem-text` 不存在 → 断言假失败，改成只在进写字页前填对应场次；② `workCapacity=3` 时计划会因补练多于 3 场，「全部完成」分支要先把剩余场次全标 done，否则 currentSlot 还不是 -1；③ 造多场次测试要给 `day.restAck = 99`，否则连着第 3 场的休息弹窗会挡住 `.q-card`。
