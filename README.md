# 宝贝每日一练

> 教材同步的每日打卡应用 · 一年级上/下册（人教版统编 2024 修订版）· 纯单机、无账号、无云同步

孩子每天打开就能看到当天的组合任务（认字 + 拼音 + 数学 + 写字）：**每天几场由家长定**（推荐工作日 1 场、周六 3 场、周日 2 场），
每场约 30 分钟，一场一场做，做完打卡攒星星；
家长只需拍照批改写字、偶尔看周报和导出备份。**PC 优先，兼容 iPad / 手机。**

---

## 一、怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **推荐** | 双击 `start.bat` | 启动本地服务器（18080 端口）并打开浏览器。照片存 IndexedDB，最稳 |
| 备选 | 双击 `index.html` | 直接能用，但浏览器会禁掉 IndexedDB → 照片降级存浏览器小仓库（最多 40 张） |

首次打开会走 3 步引导：填名字（可选这学期学哪一册）→ 选节奏 → 设 4 位家长密码。全程不到 1 分钟。
**两册进度各自保存**，家长中心随时切换。

> 换浏览器 / 换电脑 / 清理浏览器数据 = 数据丢失。**每月导出一次 JSON 备份**（家长中心 → 数据）。

## 二、孩子端怎么用

1. **今日任务**：看到 4 张卡片（认字 5 / 拼音 6 / 数学 5 / 写字 3~5 字）和「开始今天的练习」。
2. **做题**：一次一题，点选项即判分；答对 +1⭐，答错可以再试一次（第二次答对半分），两次不对会公布答案和解析。
3. **每题都有喇叭**：点一下就把题干读出来（需要系统装有中文语音包）。
4. **写字 / 写拼音**：每张卡上田字格范字和四线三格拼音并排给出（带笔顺、组词）→ 在本子上每字写一行，**写汉字还是写拼音当天自己选**，不用提前设 → 拍照上传。AI 和家长都认这两种，不会因为「只写了拼音」扣分。
5. **打卡**：三科做完 + 照片上传 = 今日完成，星星和连续天数结算。

孩子端**没有任何设置 / 删除 / 导出入口**，这些都锁在家长中心。

## 三、家长端怎么用

右上角点孩子头像切孩子，左侧/底部进「家长中心」（需 4 位密码）。

| 标签 | 能做什么 |
| --- | --- |
| 概览 | 今日场次、欠账、待批改数量、教材进度、语音与存储状态 |
| 孩子 | 添加 / 改名 / 切换 / 删除（删除会二次确认） |
| 批改 | 待批改列表 → 大图 → 四维星级 + 预置评语；维度名跟着实际写法走（汉字：笔画/结构/整洁/完成度；拼音：字母形体/占格/声调/完成度；不知道时用中性说法）；可导出评分任务包给 AI |
| 看题 | 选一天 → 看那天每场会出哪些题（语文/数学/写字、各几题）；点进去逐题看题干、选项、正确答案和解析。未来日期按「每天都按时完成」往后推演，会跟着进度往后走；只读预览，不写记录、不影响孩子进度；同样需要家长密码 |
| 设置 | **教材册次切换**、跳到指定课时、节奏（20/30/40 分钟）、语音、音效、错题复习、每天写字字数、补练是否写字、工作日/周六/周日/节假日各几场、每天最多补几场、节假日表、改密码 |
| 数据 | 导出 JSON / CSV / ZIP（含照片）、导入还原、清空（清空前自动快照） |
| AI 评分 | 导出评分任务包 / 导入结果 / 直连 OpenAI 兼容接口 |

### 每天练几场（按家长确认的口径）

- **全部由家长设定**：工作日 / 周六 / 周日 / 法定节假日各几场，每项 1~5 场；推荐值是**工作日 1、周六 3、周日 2、节假日 3**（也就是原来的固定规则）；
- 这是当天**应完成**的场次，全部做完才算打卡完成；改完对之后新生成的任务生效，今天已排好的点今日页的「按新规则重排今天」；
- 当天的第 2 场起算「**加练**」，内容顺序往前推进，写字量不缩水；
- 没做完的算**欠账**，**每天都能补**（含工作日），每天最多补几场也由家长定（推荐 2 场，可设 0 = 不补）；
- 超出当天目标的那几场算「**补练**」，写字减半（2 字），可在设置里关掉；
- **连着练到第 3 场会提醒休息**：相邻两场间隔不超过 25 分钟算「连着练」，第 3 场开始前弹一次「先歇一会儿」；真歇够了的不会再提醒，点过「我还想接着练」的同一场也不会重复弹；
- 家长中心会显示「还差 N 场，预计 X 月 X 日可补完」。

节假日表内置 2026 / 2027 两年，**以国务院当年通知为准**，可在设置里按「开始 结束 名称」逐行改。

### 题目是怎么出的（不重复、不送分）

- **全书题干唯一**：语文一上 781 题、一下 737 题，生成时用全局去重表拦重复，同一个字的读音只问一次；同一场里也不会对同一个音节问两遍。
- **拼音不再「抄字母」**：原来「d 和 i 拼起来读第四声是哪个」这种题，答案就写在题干里。现在拼读题问的是「拼出来是哪个**字**」，另外大量使用「「五」读什么？」（选项同韵不同调）、「「wǔ」是哪个字？」这类必须真会读才选得出的题。
- **认字换着问法**：同一个字第二次出现时不会再用上次的题型（拼音 / 笔画 / 组词 / 偏旁 / 结构 / 第一笔 / 听音选字），七种问法轮换；一个字在整册里的问法都用完了，就换成前面学过、还没考过的字顶上，保证每场认字题固定 5 道。
- **数学不送分**：删掉了「3 个苹果用数字几表示」这种答案写在题干里的题，改成「再添几个就够 5 个」这类要想一步的。
- **比较式填数（新增题型）**：左边一个加减算式、右边一个数，中间用 > 或 < 连接，挖掉其中一个数问「□ 里最大/最小能填几」，例如 `□ + 1 < 5`（最大 3）、`9 < □ + 4`（最小 6）、`10 − □ > 3`（最大 6）。挖第一个数、挖第二个数、算式在左边/右边四种位置都有，加减各占一半；题目按课时进度从 5 以内排到 10 以内，一上分散在「5 以内综合」「6、7 的加减法」「8、9 的加减法」「10 的加减法」「10 以内综合」五个节点，难度逐级加码。答案由程序按不等式解出来，只出「问最大就上面有界、问最小就下面有界」的组合，不会出现答案无穷大的题；解析写的是「填 4 成立、填 5 就不成立」这种孩子能自己验算的说法。
- **拼音用书写体**：`assets/fonts/Andika-Regular.ttf`（SIL OFL 1.1），单层 a / g、带全套声调，和课本一致；本机没加载成功时回退到 Segoe Print / Comic Sans。

## 四、打印

今日任务页或写字页点「🖨 打印练习单」，得到 A4 彩色练习单：

- 三大题块（认字 / 拼音 / 数学）+ 图示（emoji / SVG 图形 / 十格阵 / 积木堆）；
- 写字部分每个字 1 个描红格 + 3~5 个空白田字格，一字一行；后面再跟一段四线三格（同样有拼音描红），想写拼音就用这一段，两种格子都在同一张纸上，写哪种都行；
- 打印时选「彩色 + A4 纵向 + 默认边距」。

## 五、AI 评分怎么接

本应用不存任何密钥，提供标准接口：

```
本应用 --导出--> 评分任务包_YYYY-MM-DD.zip (manifest.json + photos/*.jpg)
        --> 你的评分 App（自带 API Key）--写回--> 结果 JSON
        --> 家长中心 · AI 评分 · 导入评分结果
```

`manifest.json` 里每条任务长这样：

```json
{
  "recordId": "w_2026-10-30_0",
  "kidId": "kxxx",
  "date": "2026-10-30",
  "slot": 0,
  "chars": ["九", "十", "六", "爸"],
  "image": "photos/2026-10-30_0.jpg",
  "prompt": "你是一位小学一年级语文老师…（完整 prompt，可直接发多模态模型）",
  "schema": { "stroke": "1-5", "structure": "1-5", "clean": "1-5", "complete": "1-5", "note": "string" }
}
```

评分 App 只需输出：

```json
[{ "recordId": "w_2026-10-30_0", "scores": { "stroke": 4, "structure": 3, "clean": 4, "complete": 5 }, "note": "间架结构再紧凑一点", "model": "gpt-4o" }]
```

导回本应用即写入写字记录并标记 `reviewedBy: ai`，之后仍可家长手动改。

> 也接受**扁平写法**：`[{ "recordId": "w_2026-10-30_0", "stroke": 4, "structure": 3, "clean": 4, "complete": 5, "note": "…" }]`。
> 只给了部分维度时，其余维度沿用原来的分；一个分数都识别不出来则整条跳过，不会误写。

也可以直接在家长中心填 `baseURL / apiKey / model`（OpenAI 兼容，支持本地 Ollama 之类）做「AI 打分」。

> **写汉字还是写拼音，不用提前定**：提示词直接告诉模型「两种都可以，孩子当天自己挑」，并同时给出两套判分标准（汉字看笔顺、结构；拼音看字母形体、四线三格占格、声调），明确「只写了其中一种也算完成，不许扣分」。
> 模型会顺带判断照片里写的是哪种，填在 `script`（`hanzi` / `pinyin`）里；这条判定会写回记录，批改页的四个维度名就跟着换成「字母形体 / 占格位置 / 声调与整洁」或「笔画正确 / 间架结构 / 整洁规范」。没判定出来时用中性说法「写法正确 / 占格结构 / 整洁规范 / 完成度」。

## 七、开发与扩展

- **无框架、无构建**：直接用浏览器打开，改完刷新即可。
- 改内容：`content/*.js` 是「节点规格 + 加载时生成」，改字表/题面刷新就生效。
- 自检：

```bash
node tools/check-content.js     # 内容层
# 页面层：浏览器打开 tools/smoke.html，或 http://127.0.0.1:18080/tools/smoke.html
```

- **加新册次**（如二年级上册）只需四步：
  1. 新建 `content/yw-2a.js`（写 UNITS 节点规格）+ `content/sx-2a.js`（写 5 题/节点）；
  2. 新字补进 `content/chars-db-*.js`，写字表用 `WritingTable.reg('yw-2a', rows)` 注册；
  3. `index.html` 引入这两个文件；
  4. `assets/js/content.js` 的 `BOOK_PAIRS` 加一行 `'yw-2a': { chinese:'yw-2a', math:'sx-2a', label:'二年级上册' }`。
  家长中心的册次切换会自动出现这个新选项，无需改页面代码。

## 八、常见问题

**Q：点喇叭没声音？**
系统缺中文语音包。Windows：设置 → 时间和语言 → 语音 → 添加语音（中文简体）。缺语音时应用会自动隐藏朗读入口，不影响做题。

**Q：照片存哪儿了？会丢吗？**
IndexedDB（`wb2-db`）。用 `file://` 打开时会降级到 localStorage 且只保留最近 40 张 —— 所以推荐用 `start.bat`。

**Q：清空浏览器数据怎么办？**
数据会没。养成每月导出 JSON 的习惯；家长中心有「超过 30 天未导出」的提醒。

**Q：什么时候切到下册？**
家长中心 → 设置 → 教材与进度，点「一年级下册」即可。上册进度会存档，切回来接着做；写字表、课文目录、题目都会一起换。

**Q：孩子中途插班 / 想跳课？**
家长中心 → 设置 → 教材与进度 → 「✏️ 跳到指定课时」，选语文/数学的单元和节次即可，历史记录和星星不受影响。

**Q：能改题目吗？**
可以，改 `content/` 下的文件；v1 不做家长自定义题库 UI。

**Q：AI 评分准吗？**
只能当参考，最终以家长评分为准；AI 分数写入后仍可手动覆盖。
