# 宝贝每日一练

> 教材同步的每日打卡应用 · 一年级上册（人教版 2024 修订版）· 纯单机、无账号、无云同步

孩子每天打开就能看到一份约 30 分钟的组合任务（认字 + 拼音 + 数学 + 写字），做完打卡攒星星；
家长只需拍照批改写字、偶尔看周报和导出备份。**PC 优先，兼容 iPad / 手机。**

---

## 一、怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **推荐** | 双击 `start.bat` | 启动本地服务器（18080 端口）并打开浏览器。照片存 IndexedDB，最稳 |
| 备选 | 双击 `index.html` | 直接能用，但浏览器会禁掉 IndexedDB → 照片降级存浏览器小仓库（最多 40 张） |

首次打开会走 3 步引导：填名字 → 选节奏 → 设 4 位家长密码。全程不到 1 分钟。

> 换浏览器 / 换电脑 / 清理浏览器数据 = 数据丢失。**每月导出一次 JSON 备份**（家长中心 → 数据）。

## 二、孩子端怎么用

1. **今日任务**：看到 4 张卡片（认字 5 / 拼音 6 / 数学 5 / 写字 3~5 字）和「开始今天的练习」。
2. **做题**：一次一题，点选项即判分；答对 +1⭐，答错可以再试一次（第二次答对半分），两次不对会公布答案和解析。
3. **每题都有喇叭**：点一下就把题干读出来（需要系统装有中文语音包）。
4. **写字**：看田字格范字和笔顺 → 在本子上每字写一行 → 拍照上传。
5. **打卡**：三科做完 + 照片上传 = 今日完成，星星和连续天数结算。

孩子端**没有任何设置 / 删除 / 导出入口**，这些都锁在家长中心。

## 三、家长端怎么用

右上角点孩子头像切孩子，左侧/底部进「家长中心」（需 4 位密码）。

| 标签 | 能做什么 |
| --- | --- |
| 概览 | 今日场次、欠账、待批改数量、教材进度、语音与存储状态 |
| 孩子 | 添加 / 改名 / 切换 / 删除（删除会二次确认） |
| 批改 | 待批改列表 → 大图 → 四维星级（笔画/结构/整洁/完成度）+ 预置评语；可导出评分任务包给 AI |
| 设置 | 节奏（20/30/40 分钟）、语音、音效、错题复习、每天写字字数、补练是否写字、周末与节假日场次、节假日表、改密码 |
| 数据 | 导出 JSON / CSV / ZIP（含照片）、导入还原、清空（清空前自动快照） |
| AI 评分 | 导出评分任务包 / 导入结果 / 直连 OpenAI 兼容接口 |

### 补练规则（按家长确认的口径）

- 每个自然日至少 1 场新内容；
- 没做完的算**欠账**，只安排在**周末（每天 2 场）和法定节假日（每天 3 场，含补工作日）**补；
- 今日实际场次 = `1 + min(欠账, 当日容量 - 1)`；补练做的是**同一个没做完的节点**，不会跳内容；
- 补练场次默认保留写字但减半（2 字），可在设置里关掉；
- 家长中心会显示「还差 N 场，预计 X 月 X 日可补完」。

节假日表内置 2026 / 2027 两年，**以国务院当年通知为准**，可在设置里按「开始 结束 名称」逐行改。

## 四、打印

今日任务页或写字页点「🖨 打印练习单」，得到 A4 彩色练习单：

- 三大题块（认字 / 拼音 / 数学）+ 图示（emoji / SVG 图形 / 十格阵 / 积木堆）；
- 写字部分每个字 1 个描红格 + 3~5 个空白田字格，一字一行；
- 打印时选「彩色 + A4 纵向 + 默认边距」。

## 五、AI 评分怎么接

本应用不存任何密钥，提供标准接口：

```
本应用 --导出--> 评分任务包_YYYY-MM-DD.zip (manifest.json + photos/*.jpg)
        --> 你的评分 App（自带 API Key）--写回--> 结果 JSON
        --> 家长中心 · AI 评分 · 导入评分结果
```

`manifest.json` 里每条任务长这样：

```json
{
  "recordId": "w_2026-10-30_0",
  "kidId": "kxxx",
  "date": "2026-10-30",
  "slot": 0,
  "chars": ["九", "十", "六", "爸"],
  "image": "photos/2026-10-30_0.jpg",
  "prompt": "你是一位小学一年级语文老师…（完整 prompt，可直接发多模态模型）",
  "schema": { "stroke": "1-5", "structure": "1-5", "clean": "1-5", "complete": "1-5", "note": "string" }
}
```

评分 App 只需输出：

```json
[{ "recordId": "w_2026-10-30_0", "scores": { "stroke": 4, "structure": 3, "clean": 4, "complete": 5 }, "note": "间架结构再紧凑一点", "model": "gpt-4o" }]
```

导回本应用即写入写字记录并标记 `reviewedBy: ai`，之后仍可家长手动改。

也可以直接在家长中心填 `baseURL / apiKey / model`（OpenAI 兼容，支持本地 Ollama 之类）做「AI 打分」。

## 七、开发与扩展

- **无框架、无构建**：直接用浏览器打开，改完刷新即可。
- 改内容：`content/*.js` 是「节点规格 + 加载时生成」，改字表/题面刷新就生效。
- 自检：

```bash
node tools/check-content.js     # 内容层
# 页面层：浏览器打开 tools/smoke.html，或 http://127.0.0.1:18080/tools/smoke.html
```

- 加新册次（如一年级下册）：新建 `content/yw-1b.js` / `sx-1b.js`，在 `index.html` 引入，
  在 `content.js` 的 `SUBJECT_BOOK` 里换映射即可，代码零改动。

## 八、常见问题

**Q：点喇叭没声音？**
系统缺中文语音包。Windows：设置 → 时间和语言 → 语音 → 添加语音（中文简体）。缺语音时应用会自动隐藏朗读入口，不影响做题。

**Q：照片存哪儿了？会丢吗？**
IndexedDB（`wb2-db`）。用 `file://` 打开时会降级到 localStorage 且只保留最近 40 张 —— 所以推荐用 `start.bat`。

**Q：清空浏览器数据怎么办？**
数据会没。养成每月导出 JSON 的习惯；家长中心有「超过 30 天未导出」的提醒。

**Q：能改题目吗？**
可以，改 `content/` 下的文件；v1 不做家长自定义题库 UI。

**Q：AI 评分准吗？**
只能当参考，最终以家长评分为准；AI 分数写入后仍可手动覆盖。
